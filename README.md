# V-shaped Antenna Response

This repository contains the Python codes used for the numerical calculations and figure generation presented in the associated manuscript on the response function of a V-shaped antenna.

## Contents

- `src/`: core antenna-response and numerical calculation codes
- `validation/`: numerical validation of the collinear limit at ψ = 180°
- `figures/`: scripts used to generate the figures in the manuscript
- `data/`: numerical output data used for selected figures

## Requirements

The codes are written in Python 3 and use standard scientific Python packages, including:

- NumPy
- SciPy
- Matplotlib

## Reproducibility

The code in `validation/` reproduces the numerical comparison between the present V-shaped formulation at ψ = 180° and the classical linear-dipole response.

The scripts in `figures/` reproduce the numerical results and figures presented in the manuscript.
